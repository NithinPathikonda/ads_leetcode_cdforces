## 🏆 The 5-Step MNC Interview Blueprint
1. **Clarify Constraints & Edge Cases**: $N$ size ($10^5 \implies O(N \log N)$ or $O(N)$, $N \le 20 \implies O(2^N)$ backtracking), negative numbers, duplicate elements, empty arrays.
2. **State Brute Force First**: Naive $O(N^2)$ or $O(2^N)$ baseline.
3. **Identify Pattern & Optimization**: Data structure / technique explanation (e.g. *“Using a Monotonic Stack reduces this from $O(N^2)$ to $O(N)$ because...”*).
4. **Dry Run on Edge Case**: Trace through custom inputs before coding.
5. **Write Clean Production Code**: Meaningful names, modular functions, accurate Big-$O$ (Time & Space).
