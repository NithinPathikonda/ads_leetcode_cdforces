## 🏆 The 5-Step MNC Interview Blueprint
1. **Clarify Constraints & Edge Cases**: $N$ size ($10^5 \implies O(N \log N)$ or $O(N)$, $N \le 20 \implies O(2^N)$ backtracking), negative numbers, duplicate elements, empty arrays.
2. **State Brute Force First**: Give the naive $O(N^2)$ or $O(2^N)$ approach to establish the baseline.
3. **Identify Pattern & Optimization**: Explain the data structure / technique (e.g. *“Using a Monotonic Stack reduces this from $O(N^2)$ to $O(N)$ because...”*).
4. **Dry Run on Edge Case**: Trace through custom inputs (e.g., all identical, sorted, descending, negative) before coding.
5. **Write Clean Production Code**: Meaningful names, modular functions, accurate Big-$O$ (Time & Space).
